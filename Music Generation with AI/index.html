🎵 AI Music Generation Studio

Deep Learning-Powered Music Composition

📚 How to Run in VSCode

🚀 Quick Start

  1. Open Visual Studio Code
  2. Create a new folder for your project (e.g., ai-music-generator)
  3. Create a file named index.html
  4. Copy all the code into this file
  5. Install Live Server extension in VSCode (by Ritwick Dey)
  6. Right-click on index.html → Select "Open with Live Server"
  7. Your browser will open automatically at http://localhost:5500

🎼 How to Use the App

  1. Step 1 - Data Collection: Click "Load MIDI Dataset" to simulate loading music data
  2. Step 2 - Preprocessing: Click "Preprocess Data" to convert music into note sequences
  3. Step 3 - Train Model: Click "Train LSTM Model" to train the AI (simulated)
  4. Step 4 - Generate: Click "Generate Music" to create new melodies
  5. Step 5 - Play: Click "Play Generated Music" to hear your AI composition
  6. Use the controls to adjust tempo, genre, and complexity
  7. Click on the piano keys to play individual notes

🧠 How It Works

  • LSTM Neural Network: Uses recurrent layers to learn music patterns
  • Markov Chains: Simplified algorithm for browser-based generation
  • Web Audio API: Generates and plays audio in real-time
  • Pattern Recognition: Learns note transitions and rhythms
  • MIDI Simulation: Generates note sequences similar to MIDI format

💡 Tips

  • Try different genres for varied musical styles
  • Adjust complexity to control pattern intricacy
  • Download generated sequences to save your creations
  • Experiment with tempo for different moods
